Thank you for your interest in contributing to this project. We welcome contributions from the community and appreciate your efforts. Please follow the guidelines below to ensure a smooth contribution process.

If you need to contact us for subjects not covered by issues or pull requests, please reach out at opensource@siradel.com.

## Issues

There are two main types of issues:

- **Feature requests**: If you have an idea for a new feature or improvement, please create a new issue and label it as `enhancement`. Provide a clear description of the feature, its benefits, and any relevant use cases or examples.
- **Bug reports**: If you find a bug in the project, please report it by creating a new issue. Provide as much detail as possible, including steps to reproduce the bug, expected behavior, and any relevant screenshots or logs. Use the `bug` label.

When an issue is marked as `wontfix`, we decided we do not wish to implement it or do not consider it a bug. This can be for various reasons, such as the issue being out of scope for the project, not aligning with our goals, or being a duplicate of an existing issue. We will provide an explanation to ensure transparency and understanding.

## Pull Requests

Issues marked with `help wanted` or `good first issue` are good candidates for contributions.

Please comment on the issue you are working on to let others know. This helps prevent duplicate work and allows for collaboration.

Larger contributions may require more discussion and planning. If you are interested in working on a larger feature or improvement, please open an issue to discuss your ideas before starting work.

To submit a pull request, please follow these steps:

1. Fork the repository and create a new branch for your changes.
2. Make your changes and commit them with clear and descriptive messages.
3. Open a pull request against the main repository, providing a clear description of your changes and the problem they solve. You must use the provided pull request template.
4. Engage in the review process, responding to feedback and making necessary adjustments to your pull request.

By contributing to this project, you agree to the following terms:

- You have the right to provide the contribution under the project's license.
